# Pruebas Integrales del Stack — Restaurante Smart

Esta carpeta alojará las pruebas de integración de extremo a extremo y validación del stack completo (verificación de contratos entre `frontend`, `backend`, `postgres-app` y flujo de reservas/pedidos en contenedores).

* Las pruebas unitarias y de endpoints del backend se ubicarán en `backend/tests/`.
* Las pruebas unitarias, de componentes y servicios del frontend se ubicarán en `frontend/src/`.
* Las pruebas integrales de stack y smoke tests se ejecutarán en las Fases 7 y 13.
